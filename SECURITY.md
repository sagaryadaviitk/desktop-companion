# Security

Desktop Companion is experimental software that can expose supported local chats and actions to a paired phone. Before enabling remote access, review the [trust boundaries](README.md#trust-and-security), [phone setup](SETUP.md#phone-access), and [acceptance checklist](COMPATIBILITY.md#destination-mac-acceptance-checklist).

## Reporting

No verified private vulnerability-reporting channel has been published for this repository yet. Do not publish security vulnerabilities, credentials, pairing codes, chat contents, private URLs, or raw logs in a public issue. If you discover a security problem, stop using the affected feature as appropriate and contact the repository owner through a trusted private channel already known to you. If you do not have one, hold sensitive details until an appropriate private channel is established. No response time or security support commitment is currently published.

Before a public trial, the owner must establish and monitor a private reporting channel. GitHub supports [private vulnerability reporting for public repositories](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository); enable and verify it as part of the visibility change, or provide another trusted private channel beforehand. Until a channel is verified, the project is not ready for public security disclosures.

For non-sensitive defects, an issue can include the source commit, OS and desktop app version, a minimal reproduction with synthetic data, and expected versus observed behavior. Check diagnostics for personal data and secrets before sharing. Never attach live configuration, database files, session records, or unredacted logs.
